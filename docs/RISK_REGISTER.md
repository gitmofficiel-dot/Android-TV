# سجل المخاطر
| الخطر | الأثر | المعالجة |
|---|---|---|
| خطأ تحديد SoC/DDR/PMIC | تعطل الإقلاع | DTB ونقوش اللوحة ومصادر موثقة |
| غياب تعريفات GPU/media حديثة | واجهة بطيئة أو فيديو غير عامل | جرد ELF/HAL واختبارات فعلية |
| فرق 32/64 بت | تعذر الإقلاع/تحميل التعريف | فحص كامل للسلسلة |
| نسخة أثناء التشغيل | استعادة غير متسقة | تدقيق بنيوي ومسار تعافٍ مثبت |
| 8GB/2GB | مساحة وأداء محدودان | قياس الحجم والذاكرة قبل الإصدار |
| نشر dump | تسريب بيانات | إبقاء الصور محلية ومراجعة الأدلة |
| كتابة boot/security | تعطل دائم محتمل | منع الكتابة حتى التحقق والموافقة |
